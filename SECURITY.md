# Security and responsible use

This project is intended for preservation, interoperability, and research on applications you own or are authorized to inspect.

The tool does not decrypt FairPlay-protected executables, bypass platform access controls, or download application packages. It accepts an already decrypted executable as an optional input and verifies the recoverable structure around it.

Do not attach proprietary IPAs, APKs, decrypted executables, signing material, device identifiers, or credentials to public issues. Report a vulnerability privately through GitHub's security-advisory feature.
